# 🔗 Görev 4: Haberleşme Projesi

## 🎯 Vizyon ve Amaç
Öğrenilen haberleşme protokollerini (UART, I2C, SPI veya simüle edilmiş CAN Bus) pratiğe dökmek ve cihazları birbiriyle başarılı şekilde konuşturarak sistem entegrasyonu vizyonu kazanmak.

## 📝 Görev Detayları
1. Öğrendiğiniz protokollerden en az birini kullanarak iki veya daha fazla cihazın haberleştiği bir senaryo tasarlayın.
2. Bu proje tamamen **sizin kendi tasarımınız** olmalı (Örn: I2C ile ekran kontrolü, UART ile iki Arduino'nun konuşması vs.).
3. Devre şemasını çizin ve kodlarını yazın.
4. Fiziksel veya simülasyon ortamında projenin çalıştığını doğrulayın.
